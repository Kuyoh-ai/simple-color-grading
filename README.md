# Simple Color Grading

ブラウザだけで完結する、カラーグレーディングに特化した画像編集ツールです。GitHub Pages でそのまま動作する静的 SPA で、PC / スマートフォンの両方に対応したスクロールの発生しないレスポンシブ UI、グレースケール基調の配色、ダークモードを備えています。画像はサーバーに送信されず、すべて WebGL2 でローカル処理されます。

## 機能

- **入出力**: JPEG / PNG / WebP / GIF / BMP / AVIF などブラウザが読める形式を読み込み（ファイル選択・ドラッグ&ドロップ・ペースト）。JPEG / PNG / WebP で書き出し（品質・出力サイズ指定）。
- **プリセット比較**: 読み込んだ画像に各プリセットを適用したサムネイルを一覧表示。カテゴリ（映画 / フィルム / カメラアプリ / モノクロ / イラスト）で絞り込み。
- **比較表示**: 「比較」ボタン（またはスペースキー）を押している間だけ元画像を表示。「分割」で境界をドラッグできる分割比較、「並べて」で元画像と補正後を並列表示（画面に合わせて横並び / 縦並びを自動選択）。
- **お気に入り**: サムネイル右上の ★ でお気に入り登録（ブラウザの localStorage に保存）。お気に入りは一覧の最上部に表示され、「★ お気に入り」カテゴリで絞り込みもできます。
- **重ねがけ**: Shift+クリック（Ctrl/⌘+クリック）またはタップ長押しで複数のプリセットを同時に適用。番号順に直列処理され、パネル内のチップで順序変更・個別のスライダー編集・解除ができます。書き出しにも反映されます。
- **強度調整**: 各プリセットに「適用強度」スライダー＋プリセット固有の複数スライダー（発光の不透明度、ぼかし半径、色収差、ノイズ量など）。「調整」タブでは露出・コントラスト・色温度・彩度・明瞭度などをプリセットの上に加算。
- **イラスト向け仕上げ**: 解説記事で紹介される手順をシェーダーで再現。
  - アニメ塗りディフュージョン: 複製 → ガウスぼかし → スクリーン合成 → 不透明度 20〜40%（レベル補正で明部のみ抽出可）
  - ソフトフォーカス / グロー効果 / 加算発光 / オーバーレイぼかし
  - 薄いノイズ仕上げ: パーリンノイズ（値ノイズ 3 オクターブ）をオーバーレイ・不透明度 20% 前後で合成
  - 大陸塗り風仕上げ: 影を寒色・光を暖色に分離する色相差、高コントラスト・高彩度、覆い焼き風の加算発光、色収差、シャープ、グラデーションマップ
  - 逆光加工 / 色収差 (RGBずらし) / アニメスクショ風 / グラデーションマップ / 厚塗りマット / 紙テクスチャ など
  - CLIP STUDIO TIPS「フィルターで作品を仕上げる」(oyunorka) の手順を再現: フィルター仕上げセット（パーリンノイズ → 周辺ぼかし → シャープ → 色調補正 → RGBずらし）、周辺ぼかし（選択範囲ぼかし風）、シャープ仕上げ、色調補正レイヤー仕上げ、パーリンノイズ＋ソフトぼかし
- **イラストを壊さない補正**:
  - 白地・肌の保護: 色かぶり系の補正（色温度・スプリットトーン・グラデーションマップなど）から紙の白と肌色を守り、明るさの変化だけを反映
  - 陰影の色づけ: 広域ぼかしと比べて「周囲より暗い部分」だけを陰影と判定し、影色を乗算・彩度アップ（黒髪や濃い服を影と誤認しない）。明部には光色をソフトライト
  - 主線の保護: 周囲より暗い細い線を検出し、発光・ディフュージョンで線がグレーに浮かないよう保護。ソフトフォーカスは比較(明)合成で線と瞳のピントを維持
  - 撮影処理: 画面の角から差す入射光と、反対側のパラ（グラデーション影）。光源の方向と広がりを調整可能
  - グラデーションマップのソフトライト / カラー合成
- **セルルック変換**: 明度の階調化（バンド数・境界の柔らかさ・目や線など細部の保持）、既存の線だけを拾う DoG 型の主線検出（写真向けに Sobel 輪郭検出も選択可）、影へのコミック調ハーフトーンをシェーダーで実装。ベーシック / アメコミ調 / ソフトセル / 主線のみ。

## 技術

- 依存ライブラリなし（HTML + CSS + ES Modules）。ビルド不要。
- WebGL2 の 3 パス構成: 色補正パス → ダウンサンプル + 分離ガウスぼかし（発光用と、陰影判定用の広域ぼかしの 2 系統） → 合成パス（陰影の色づけ / 発光 / ハレーション / 明瞭度 / シャープ / 色収差 / 入射光・パラ / ノイズ / 周辺減光）。
- ぼかし半径やノイズ粒サイズは画像サイズに対する相対値で扱うため、プレビューと書き出し結果が一致します。

## ローカルで動かす

ES Modules を使用しているため、`file://` ではなく HTTP サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## GitHub Pages へのデプロイ（自動）

`.github/workflows/pages.yml` が `main` および既定ブランチ（現在は `claude/sharp-lamport-gx569c`）への push のたびにリポジトリ直下を GitHub Pages に自動デプロイします。`actions/configure-pages` の `enablement: true` により初回実行時に Pages が自動で有効化されるため、手動設定は不要です（Actions → Deploy to GitHub Pages から手動実行も可能）。公開 URL はワークフローの `github-pages` 環境に表示されます。

## 制限事項

- WebGL2 が必要です（主要なモダンブラウザで利用可能）。
- 書き出しサイズは端末の GPU 上限に合わせて自動的に制限されます（スマートフォンで約 16MP、PC で約 24MP）。
- WebP 書き出しに対応していないブラウザでは自動的に PNG で保存されます。
